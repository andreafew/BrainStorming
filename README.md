# Consultora de Sistemas Operativos — Proyecto integrado

Recomendación de sistema operativo para dos clientes, con el mismo método:
- **Cliente A:** Estudio Contable (30 notebooks, servidor en la nube).
- **Cliente B:** Laboratorio de informática de la universidad (servidor en la nube).

Comparamos **Windows 11** y **Ubuntu** con las mismas pruebas; cada cliente tiene 10 criterios propios (4 compartidos, con pesos distintos).

## Contenido
- `backlog/`: backlog unificado (Excel y CSV) y script de importación. Une el backlog del grupo con tareas agregadas (columna Origen: Existente, Modificado o Agregado). Se elaboró con asistencia de IA y lo revisa y valida el equipo.
- `plan_de_evidencias.csv`: qué evidencia necesita cada tarea.
- `evidencia/`: capturas y datos propios, por sprint.
- `plantillas/`: bitácora, matriz de resultados y comandos equivalentes.
- `documentos/`: propuestas de trabajo (compra, viaje, licencias, backups, SharePoint, primer día, servidor en la nube). Los supuestos están marcados.
- `informe/`: plantilla del informe (la recomendación va primero).
- `.github/workflows/`: validación del informe (CI) y armado del PDF al crear un tag `v*` (CD).
