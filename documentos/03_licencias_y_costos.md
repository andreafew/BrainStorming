## Riesgos
| Riesgo | Mitigación |
|---|---|
| Tango no corre en Ubuntu | Windows 11 Pro para el Estudio |
| Máquinas existentes sin TPM 2.0 | Verificar con la tarea de requisitos de hardware de Windows 11; si no cumplen, reemplazarlas |
| Dependencia de internet (M365) | Medir conexión del Estudio; backup local |
| Pérdida de datos al migrar | Backup y restauración probada (04) |
| Costo en dólares y variación del tipo de cambio | Presupuesto con fecha y cotización indicada |
