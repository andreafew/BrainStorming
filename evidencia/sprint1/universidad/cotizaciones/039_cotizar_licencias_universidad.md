# 39 · Cotizar licencias para la Universidad (Windows 11 educativo/Pro; Ubuntu sin costo de licencia)

**Cliente:** B - Universidad · **Sprint:** 1 · 

## Qué se pidió
Obtener la cotización oficial de licencias para la Universidad (Windows 11 educativo o Pro, y Ubuntu sin costo), con fuente y fecha, para comparar costos.

**Criterio de aceptación:** Cotización oficial con fuente y fecha, incluyendo precio educativo si existe y el soporte opcional de Ubuntu.

## Qué se cotiza
| Producto | Qué es |
|---|---|
| Windows 11 Education | Sistema operativo, edición educativa, por suscripción o volumen académico |
| Windows 11 Pro Education | Sistema operativo, edición educativa con licencia perpetua |
| Ubuntu | Sistema operativo sin costo de licencia |
| Soporte opcional de Ubuntu (Ubuntu Pro Base) | Suscripción anual de soporte, opcional |

**Cantidad:** 25 equipos del laboratorio.

## Qué se hizo
Se consultaron las fuentes oficiales de Microsoft y de Ubuntu para cotizar el sistema operativo de los 25 equipos del laboratorio: Windows 11 Education, Windows 11 Pro Education, Ubuntu y el soporte opcional de Ubuntu. Para cada producto se registró el tipo de licencia, el precio unitario, el total para 25 equipos, la fuente y la fecha de consulta.

### Observaciones y justificación técnica
- **Windows 11 Education (opción recomendada):** costo cero si la Universidad tiene un contrato activo de Microsoft 365 (A3/A5), porque el Student Use Benefit cubre las licencias del laboratorio sin costo adicional. Incluye funciones avanzadas de bloqueo (Kiosk Mode).
- **Windows 11 Pro Education (alternativa de compra):** solo si no hay convenio previo. Pago único perpetuo mediante un distribuidor educativo autorizado. Se cotiza como actualización masiva (upgrade) para las terminales del laboratorio.
- **Soporte opcional de Ubuntu (Ubuntu Pro Base):** plan que proporciona parches automáticos de seguridad y cumplimiento legal por 10 años, ideal para un entorno educativo sin requerir soporte telefónico corporativo.

## Conclusión
Para los 25 equipos del laboratorio, la licencia de Windows 11 Education cuesta USD 0 si la Universidad tiene un contrato activo de Microsoft 365 (A3/A5). Si no lo tiene, la alternativa es Windows 11 Pro Education, con un pago único de USD 562,50. Ubuntu no tiene costo de licencia, y su soporte opcional (Ubuntu Pro Base) cuesta USD 625,00 por año. En licencias, la opción más económica es Ubuntu, sin costo, o Windows 11 Education si existe el contrato. Falta confirmar con la Universidad si tiene ese contrato.
