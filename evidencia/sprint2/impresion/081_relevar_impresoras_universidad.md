# 81 · Relevar impresoras de la Universidad

**Cliente:** B - Universidad · **Sprint:** 2 ·

## Qué se pidió
Relevar modelo, conexión y driver disponible de cada impresora de la Universidad para Windows 11 y Ubuntu.

**Criterio de aceptación:** Planilla con modelo, conexión y driver disponible para Windows 11 y Ubuntu.

## Qué se hizo
Se inventariaron las impresoras del laboratorio. Se detectó que solo tienen conexión USB, lo que impide su uso en red. Se validó la compatibilidad de drivers para Windows 11 y Ubuntu.

## Datos y resultados
°Impresoras existentes: 2 (solo USB).
°Drivers: No hay drivers oficiales para Ubuntu.
°Cantidad necesaria: 1 impresora cada 8-10 equipos (2 impresoras para 25 PCs).

## Resultados 
Se propuso la compra de un Print Server (adaptador USB a Ethernet) para convertir las impresoras en dispositivos de red, respetando la restricción presupuestaria.

## Conclusión
La solución del Print Server permite reutilizar el hardware existente y cumple con el requisito de conectividad para los 25 equipos.
