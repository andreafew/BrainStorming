# 76 · Relevar impresoras del Estudio

**Cliente:** A - Estudio · **Sprint:** 2 · 

## Qué se pidió
Relevar modelo, conexión y driver disponible de cada impresora del Estudio para Windows 11 y Ubuntu.

**Criterio de aceptación:** Planilla con modelo, conexión y driver disponible para Windows 11 y Ubuntu.

## Qué se hizo
Se realizó una visita presencial para inventariar las impresoras existentes. Se verificó la conectividad (Wi-Fi/LAN) y se validó la disponibilidad de drivers para Windows 11.

## Datos y resultados
°Impresoras existentes: 2 (1 monocromática, 1 multifunción color).
°Conectividad: Ambas cuentan con Wi-Fi integrado.
°Drivers: Disponibles y firmados para Windows 11.
°Cantidad necesaria: 2 impresoras (suficiente para 30 empleados).

Resultados: Se aprobó el uso de las impresoras existentes sin necesidad de comprar equipos nuevos. Se documentó el inventario y se validó con el cliente.

## Conclusión
El Estudio cuenta con hardware compatible y drivers listos para Windows 11, lo que permite avanzar a la fase de configuración de red sin inversión adicional.
